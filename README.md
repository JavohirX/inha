# IUT CSE materials

Unofficial student archive of **Inha University in Tashkent** Computer Science and Engineering course materials. Lecture slides, assignments, quizzes, exams, projects, references, and some student work — organized by year and semester.

## Contribute

**If you have files you think this repo should contain, add them.** Missing lecture slides, old quizzes, exam samples, notes, lab code, project briefs, syllabi, textbooks, solutions — anything that would have helped you take the course.

You do not need permission first. Open a [pull request](https://github.com/JavohirX/inha/pulls) with whatever you have.

A useful messy upload is better than nothing. Matching the folder layout below is appreciated; if you are not sure where something goes, dump it in the closest course folder and say so in the PR. Paths can be cleaned up later.

Want write access so you can push directly? Open an [issue](https://github.com/JavohirX/inha/issues) and ask.

Please do not dump unrelated junk.

## Layout

```
<year-semester>/<course-abbrev>/<kind>/...
```

Year folders run `1-freshman-fall` through `8-senior-spring`.

Common `kind` folders (a course may have only some of these):

| Folder | What goes there |
| --- | --- |
| `lecture-slides` | Lecture PDFs, PPT, notebooks |
| `assignments` | Assignment briefs and lab tasks |
| `homeworks` | Homework sets / solutions |
| `quizzes` | Quizzes |
| `exams` | Midterms, finals, past papers |
| `projects` | Project briefs, rubrics, reports |
| `submissions` | Student solutions / code |
| `references` | Textbooks and extra reading |
| `syllabus` | Syllabus and course outline |
| `others` | Everything else that still belongs |

There is also an interactive curriculum map: [`socie_cse_curriculum.html`](socie_cse_curriculum.html).

## Clone

```bash
git clone https://github.com/JavohirX/inha.git
```

The repo is large (~2.5 GB) because lecture PDFs are stored as normal git files.

## Adding files

1. Put files under the matching year / course / kind folder. Create folders if they are missing.
2. Prefer lowercase kebab-case names (`week-3-quiz.pdf`, not `Week 3 QUIZ.PDF`).
3. Open a pull request and write one sentence about what you added.

That is it.
