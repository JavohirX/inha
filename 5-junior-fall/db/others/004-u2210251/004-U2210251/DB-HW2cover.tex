\begin{abstract}
\noindent

Our team worked on Homework 2 for the Database (SOC-3020) course, which involved applying SQL querying techniques to a MySQL database (UniversityDB) using phpMyAdmin. The tasks included:

\begin{enumerate}
    \item Rewriting and executing existing SQL queries from class materials.
    \item Translating English queries into SQL.
    \item Creating complex SQL queries for various data retrieval tasks, such as joins, subqueries, and aggregations.
    \item Documenting queries and results with screenshots.
    \item Compiling everything into a LaTeX document according to the submission guidelines.
\end{enumerate}
The main challenge was accurately translating English queries into efficient SQL and ensuring the results were correct. Our team collaborated by dividing tasks such as writing queries, taking screenshots, and preparing the LaTeX document.
\end{abstract}
